# Real-Time Currency Converter & Trend Visualizer

A responsive, high-performance web application for real-time currency conversion, 30-day historical trend analysis, and travel budgeting.

## Tech Stack
- **Backend**: FastAPI, SQLite, HTTPX, Uvicorn (Python 3)
- **Frontend**: React (Vite), Tailwind CSS v4, Lucide React, Recharts

## Setup & Running

### Backend
```bash
cd backend
source venv/bin/activate
pip install -r requirements.txt
python -m app.main
```
The backend will run on `http://127.0.0.1:8000`.

### Frontend
```bash
cd frontend
npm install
npm run dev
```
The frontend will run on `http://localhost:5173`.
